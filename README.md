# AceMyInterview

**AI-Powered Interview Simulator with Real-Time Feedback**

[![Live Demo](https://img.shields.io/badge/Demo-Link-blue)](https://aiksvid.netlify.app/)

---

## 🚀 Overview

**AceMyInterview** is an AI-driven mock interview platform that simulates real-world technical interviews, delivers domain-specific questions using Google Gemini API, and provides real-time feedback along with personalized analytics.

---

## ⚙️ Setup Instructions

### **Prerequisites**

- Node.js >= 18  
- MongoDB Atlas or Local Instance  
- Google Gemini API Key (for AI question generation)
